# Research_Project_Sinhala_Learning

Project Overview

This project is an interactive Sinhala learning application designed for children aged 7–12, focusing on real-time voice feedback, pronunciation accuracy, and gamified learning.

The app uses karaoke-style word highlighting while sentences are spoken using Text-to-Speech (TTS). Children repeat the sentence, and the system provides real-time pronunciation feedback, highlighting words in:

🟢 Green – correctly pronounced

🔴 Red – mispronounced

⚪ Gray – skipped

Immediate feedback is given through voice responses, points, and retry prompts to reinforce learning.

The system also includes:

Object recognition and pronunciation: Detected objects are identified and pronounced in Sinhala.

Sinhala text recognition: Text is captured via camera or keyboard input, processed, and converted into meaningful images.

Gamified Sinhala storytelling: Interactive folk stories with narration, animations, points, badges, and offline support to promote language learning and cultural awareness.

The application is developed using React Native (Expo) and Unity, integrating ASR, TTS, computer vision, and gamification to provide an engaging and culturally rich Sinhala learning experience.
